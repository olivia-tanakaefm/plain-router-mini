# plain-router-mini

Build engineer / Linux / remote

顺手写的命令行工具


## 用法

```bash
cat data.txt | cargo run
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/Ines11/plain-router-mini.git
cd plain-router-mini
cargo build --release
```
